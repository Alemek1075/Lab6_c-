    УМОВА ЗАВДАННЯ Написати сопрограму, що генерує послідовність випадкових натуральних чисел з проміжку [1, 256]. Для парних чисел сопрограма має передавати керування сопрограмі A, яка виводить число. Для непарних чисел сопрограма має передавати керування сопрограмі B, яка виводить квадрат числа. Реалізувати логіку передачі керування в контролері очікування.
    ОПИС РЕАЛІЗАЦІЇ ПРОГРАМИ Програму розроблено мовою C++ з використанням стандарту C++20, який підтримує безстекові співпрограми (stackless coroutines).
Архітектура рішення базується на наступних компонентах:
Структура Task: Використовується як тип повернення для всіх співпрограм. Вона містить вкладену структуру promise_type, яка відповідає за життєвий цикл співпрограми (створення, призупинення, завершення) та зберігання поточного значення (цілого числа), що передається між генератором та споживачами.
Механізм передачі керування (TransferControl): Реалізовано користувацький об'єкт очікування (awaiter) під назвою TransferControl. Його метод await_suspend приймає дескриптор поточної співпрограми та повертає дескриптор цільової співпрограми (target). Це дозволяє виконувати симетричну передачу керування (Symmetric Transfer) без переповнення стеку, перемикаючись безпосередньо між генератором і споживачами.
Логіка співпрограм:
    Генератор: Ініціалізує генератор випадкових чисел (діапазон 1-256). У циклі створює число та перевіряє його парність.
    Якщо число парне: записує значення у promise_type співпрограми A та передає їй керування через TransferControl.
    Якщо число непарне: записує значення у promise_type співпрограми B та передає їй керування. Після генерації визначеної кількості чисел (у даному випадку 10) генератор завершує роботу програми.
    Сопрограма A (coroutineA): Працює у нескінченному циклі. Очікує на отримання значення, виводить повідомлення про отримання парного числа в консоль, після чого повертає керування назад генератору.
    Сопрограма B (coroutineB): Аналогічно працює у циклі. Очікує на значення, обчислює його квадрат та виводить результат (непарне число та його квадрат) у консоль, після чого повертає керування генератору.
Головна функція (main): Створює контекст виконання, ініціалізує екземпляри співпрограм A, B та генератора, зв'язує їх між собою та запускає виконання генератора.
